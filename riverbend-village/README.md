# Riverbend Village

A charming single-file browser game for children ages 8–12. Help a small village solve a dry-season water shortage by exploring, listening to villagers, building water systems, testing over 7 days, and improving your design.

## How to open

1. Open `index.html` in a modern browser (Chrome, Firefox, Safari, or Edge), **or**
2. From this folder, run a simple local server:

```bash
cd /workspace/riverbend-village
python3 -m http.server 8765
```

Then visit: http://localhost:8765/

No internet connection or CDN is required — CSS and JavaScript are inline.

## How to play (about 10–20 minutes)

1. **Start** — Read the dry-season challenge, then click **Start Exploring**.
2. **Explore** — Click villagers (Maya, Arun, Rosa, Eli, Jordan) and places (well, stream, farm, school, workshop) to learn what the village needs. Open **Needs** anytime.
3. **Build** — Pick a card from the build menu, then tap a glowing **Build** plot. Use **Connect Mode** to link collectors/pumps to tanks. You start with **10 materials**.
4. **Test** — Click **Run 7 Days**. Watch weather and day-by-day effects (Slow or Skip available).
5. **Reflect** — Read your Village Report Card, answer 3 short questions, then **Improve My Design**, **Start Again**, or **Finish for Today**.
6. Earn the **Community Inventor** badge when several metrics look healthy and fair.

## Parent / Educator

Use the **Parent** button (not part of the main kid flow) for learning goals, skills, and a record of the child's design. Villagers are fictional characters in a learning game.
